[D-001] Hardcoded rate limit value (1000 req/s)
  Severity : LOW
  Detail   : Rate limit is hardcoded in main.go instead of reading from config.
  Impact   : Requires code change to adjust rate limits.
  Suggestion: Add RateLimit config section to internal/config and read from env.

[D-002] No per-route rate limit tiers
  Severity : LOW
  Detail   : All routes share the same 1000 req/s limit. Auth endpoints
             (login/register) may need stricter limits to prevent brute force.
  Suggestion: Implement per-path or per-group rate limit configurations.

[D-003] RBAC only covers API Keys routes
  Severity : MEDIUM
  Detail   : Only API Keys management routes are protected by RBAC.
             Anomaly status updates and forecast generation may also
             need role-based restrictions.
  Suggestion: Audit remaining routes and add RBAC where appropriate.

[D-004] Default RBAC role is "admin"
  Severity : LOW
  Detail   : Admin role string "admin" is hardcoded. Different deployments
             may use different role names.
  Suggestion: Make RBAC roles configurable via environment or config.
